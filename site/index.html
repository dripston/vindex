Evals that actually read Hinglish.

Your English eval suite can't tell when your bot answers a Hinglish user in Devanagari, or when your LLM judge misreads the Hindi it's grading. vindex can. Two of its four checks need no LLM and no API key.

        Workflow
        
One command in CI.
One line in your test suite.

        
Point vindex run at a JSONL, JSON or CSV export. Column names from DeepEval, promptfoo and Ragas just work.

      

      

        

          
          
          
          
          
          
        


# cases.jsonl — one object per line
# {"prompt": "Mumbai kahan hai?", "response": "...", "gold": "...", "trace": "..."}

$ vindex run cases.jsonl                    # script_adherence (+ check_trace on rows with a trace)
$ vindex run cases.jsonl -m script,judge    # add the LLM judge
$ vindex run cases.jsonl --fail-under 0.95 -o report.json
$ vindex run cases.csv -f markdown > report.md

$ vindex check "Mumbai kahan hai?" "मुंबई महाराष्ट्र में है।"
$ vindex detect "Kal office aa raha hai kya?"


# .github/workflows/evals.yml
name: evals
on: [pull_request]
jobs:
  indic:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-python@v5
        with: { python-version: "3.12" }
      - run: pip install vindex
      - run: vindex run evals/cases.jsonl --fail-under 0.95
        # a markdown report is added to the job summary automatically


import pytest
from vindex import script_adherence

@pytest.mark.parametrize("prompt", [
    "Mera refund kab aayega?",
    "मेरा रिफंड कब आएगा?",
    "என் பணம் எப்போது திரும்ப வரும்?",
])
def test_bot_replies_in_users_script(bot, prompt):
    result = script_adherence(prompt, bot(prompt))
    assert result.passed, result.reason


# examples/integrations/deepeval_vindex.py
from deepeval import evaluate
from deepeval.test_case import LLMTestCase
from deepeval_vindex import ScriptAdherenceMetric

case = LLMTestCase(
    input="Mumbai kahan hai?",
    actual_output="Mumbai Maharashtra ki rajdhani hai.",
)
evaluate([case], [ScriptAdherenceMetric()])
